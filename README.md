# Tilbudsagent · Kobbermølle Fragt ApS

Et repo til Business Aabenraa den 1. oktober 2026: én masterprompt bygger en tilbudsagent for Kobbermølle Fragt ApS, en opdigtet vognmand i Padborg, og lader den behandle otte henvendelser. Alle kunder, priser og henvendelser er opdigtede.

Repoet er tomt med vilje. Alt bygges af masterprompten, som ligger på ai-savvy.dk/opgaver/business-aabenraa. Resultatet lander som en pull request, som et menneske læser og godkender. Intet sendes.

Lavet af ai-savvy (ai-savvy.dk).
